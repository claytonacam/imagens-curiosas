# Treta no Planalto — Edição Presidencial

Jogo de luta 2D estilo arcade (paródia) com **Bolsonaro vs Lula**, feito em HTML5 Canvas puro, sem dependências, em um único arquivo (`index.html`).

## Como jogar

Abra o `index.html` no navegador e clique em uma opção do menu (ou use ↑ ↓ e ENTER).

| Ação | Jogador 1 | Jogador 2 |
|---|---|---|
| Andar / pular / agachar | `A` `D` `W` `S` | `←` `→` `↑` `↓` |
| Soco | `F` | `K` / `Num1` |
| Chute (agachado = rasteira) | `G` | `L` / `Num2` |
| Especial / Super | `H` | `Ç` / `Num3` |

- **Defender:** segure para trás (agachado para defender a rasteira).
- **Super:** a barra SUPER enche ao bater e apanhar; com ela cheia, o especial vira super.
- `P` pausa, `M` liga/desliga o som. No celular aparecem botões na tela.

Modos: 1 jogador contra a CPU (3 dificuldades) ou 2 jogadores no mesmo teclado. Melhor de 3 rounds, 99 segundos cada.

| Lutador | Especial | Super |
|---|---|---|
| Bolsonaro | Arminha! | Motociata! |
| Lula | Estrela! | Faz o L! |

## Fotos dos lutadores

A cabeça de cada lutador pode ser uma foto real, recortada em círculo:

1. **No repositório:** coloque `img/bolsonaro.png` e `img/lula.png` (também aceita `.jpg`, `.jpeg`, `.webp`).
   Use retratos com o rosto centralizado; o jogo recorta um quadrado do centro (um pouco acima, em fotos verticais).
2. **No navegador:** use os botões "Escolher foto" abaixo do jogo. A foto fica salva no navegador.

Sem foto, o jogo desenha caricaturas.

> Se usar fotos de terceiros (ex.: Agência Brasil / Wikimedia Commons), respeite a licença e dê o crédito.
